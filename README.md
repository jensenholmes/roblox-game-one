# roblox-game-one

A Roblox game, built as a learning project in software development.

## Project layout

| Folder | What's in it |
|---|---|
| `design/` | Game design document: concept, core loop, features, UI/UX |
| `code/` | Luau source (`src/`) and automated tests (`tests/`), synced into Studio by Rojo |
| `art-audio/` | Style guide, asset list, and `.rbxm` models synced by Rojo |
| `learning/` | Journal, jargon list, and notes on the software development lifecycle |
| `docs/adr/` | Records of the big decisions and why they were made |

Each folder has a `CLAUDE.md` with the rules for that role.

Tasks are tracked in GitHub Issues.
